# Inside the Industry — LinkedIn Post Template (Short-Form)

> **Format:** LinkedIn company page post (short-form)
> **Companion:** Every LinkedIn post has a corresponding full-length blog post on the Sageloom website. The LinkedIn post is a highlight reel that links to the blog for the complete analysis.
> **Length:** 400–600 words (LinkedIn truncates at ~600 words on mobile)
> **Purpose:** Grab attention, deliver the most interesting insights, and drive traffic to the full blog post.

All LinkedIn posts published under this initiative must adhere to Sageloom's core editorial standard: **rigorous, educational, hype-free, and highlighting student analytical capability**. No corporate jargon, no generic motivational fluff, and no exaggerated claims.

---

## 2. What Goes in LinkedIn vs. What Goes in the Blog

| Content Area                    | LinkedIn Post | Blog Post |
|---------------------------------|:---:|:---:|
| Opening hook / misconception    | Yes | Yes |
| Biological challenge (summary)  | Yes | Yes (expanded) |
| Pipeline overview (highlights)  | Yes | Yes (step-by-step) |
| Customer deliverable            | Yes | Yes |
| Skills takeaway                 | Yes | Yes (full skills map table) |
| Data landscape (formats, DBs)   | No  | Yes |
| Teams & roles breakdown         | No  | Yes |
| AI/ML deep dive                 | No  | Yes |
| Industry context & competitors  | No  | Yes |
| Critical analysis & limitations | No  | Yes |
| Full source citations           | Pinned comment | In-article table |
| Pipeline diagram                | No  | Yes |
| Career entry points             | No  | Yes |

**Key principle:** LinkedIn shows the *most interesting* parts. The blog shows *everything*. The reader should feel "I need to click that link to get the full picture."

## 3. Pre-Publication Quality Gate Checklist

Before submitting this draft to the Board via Paperclip `request_confirmation`:
- [ ] **Zero Hyperbole:** Removed words like "disruptive", "revolutionary", "game-changing", or "miraculous".
- [ ] **Accurate Technical Terms:** Tool names and algorithms are spelled correctly (e.g. `Nextflow`, `GATK`, `PyTorch`, `scRNA-Seq`).
- [ ] **Student Attribution:** Student investigator is credited accurately with their permission.
- [ ] **Company Tagging:** Company tag is verified on LinkedIn.
- [ ] **Blog Link Included:** Full blog post URL is embedded in the post body.
- [ ] **Source Link in Comments:** Prepare the top 3 public citations to pin as the first comment on the post.
- [ ] **Companion Blog Post:** The full blog post has been submitted for Board approval alongside this LinkedIn draft.
- [ ] **Board Approval Acquired:** Never publish directly without Board sign-off.
